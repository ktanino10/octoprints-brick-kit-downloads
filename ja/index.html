PHYSICAL TRIAL / ISSUES REPORTED

試してわかった、
次に直すこと。

「小さくて作りにくい」
「穴がプラスチックで埋まっている」

細かさだけでは、組み立てやすさにつながりませんでした。穴詰まりは超音波洗浄の前から起きていた、という追加報告も記録しています。原因はまだ特定していません。

0.2 mmノズル装着は事前に確認。実際のプロファイル・層高・材料銘柄や、条件別の保持力は未確定です。

DESIRED PRINT OPTIONS / DISCUSSION

印刷方法も、選べるように。

「別々に印刷して後で組み立てる方法」と、
「最初からすべて印刷する方法」が希望されています。

分割して組み立てる方法：現在あるのは、この方式の未検証の試作データです。
「最初からすべて印刷する方法」：組立不要の一体造形か、別部品を同じプレートへ並べる一括印刷か、意図を確認中です。どちらも新しい対応データは作成・承認していません。

これは今後の希望の記録です。組立ビュー用CADを一体印刷用や印刷準備済みとは扱いません。現行の課題を踏まえ、全数印刷は保留のままです。

外観の細かさと、
手に持つ一部品の大きさを、
別々に考える。

LEGOのstud-and-tubeの原理を参考に、およそ8 mmピッチの2×2・2×4・1×2など、手でつかめる共通ブロックを中心にする方向を話し合っています。細部はプレート等で補う考え方です。

新しい設計案は未採用です。約180 mmの外観の厳密な維持、市販LEGO互換、FDMでの成形・保持力は、まだ保証できません。この公開のために新しいCADや印刷データは生成していません。
