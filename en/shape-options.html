Distinguish a single print from separate-part assembly.

Using r2 for a single print remains a proposed use. The existing r2 data is an arrangement of many separate parts, not a guaranteed watertight single body or ready-to-print monolithic model. One-piece output would require separate geometry preparation and slicing validation. This study does not create that version or any print job.

r3 is designed as separately printed parts for later assembly. Both alternatives retain that approach and remain unselected studies. A better-looking image does not validate physical handling, fit, retention or stability.
