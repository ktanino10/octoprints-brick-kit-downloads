## 内容

| 部品 | 数量 |
|---|---:|
| ノッチ1～4で区別した受け | 各1、計4 |
| 共通の雄キー | 4 |
| 段違い結合の下側 | 2 |
| 段違い結合の上側 | 1 |
| 合計 | **11** |

受けのノッチ数1 / 2 / 3 / 4は、直径差 **−0.05 / 0 / +0.10 / +0.20 mm** に対応します。
直径差は「受けの直線穴径 − 雄軸径」で、片側差ではありません。
−0.05 mmは意図的な公称干渉です。同じ雄キーでも現物差や摩耗があるため、条件ごとに別のキーを使います。

## 別のパソコンのBambu Studioで行う準備

1. 形状3MFを開き、実際のプリンターに対応する **Bambu Lab P1S / 0.2 mm nozzle** の既存プリセットを選びます。
   そのプリセットが見つからない場合は、別機種や0.4 mm用に代用せず止めてください。
2. 実際に使うプレート種類とPLAを選びます。PLAの銘柄・色、プレート種類はこのパックでは指定していません。
   対応する実在のGeneric PLAは暫定候補になり得ますが、実際の材料との確認が必要です。
   層高・温度・速度などは対応する既存プロファイルを使用し、使用した名称と値を記録します。
3. 11部品であることを確認します。**受け穴は下向き、雄軸は上向き、底面はz=0**です。
   自動回転・拡大縮小で姿勢や大きさを変えないでください。
   配置は公称256×256 mmの範囲内ですが、選択した機種・プレート上で再確認します。
4. ローカルでスライスし、レイヤープレビューを確認します。
   受けの穴が入口から意図せず埋まっていないか、細い雄軸の経路が欠落していないか、
   穴の屋根に橋渡しと上面の経路があるか、不要なサポートが穴を塞いでいないかを確認します。
   警告や判断できない箇所があれば、そのまま印刷へ進まず確認してください。
5. 選択した機種・ノズル・材料・処理プロファイル、層高、警告とプレビューを記録し、
   **元ファイルとは別名**でBambu Studioプロジェクトをローカル保存します。
   時間とPLA量は、実際にその設定でスライスした結果だけを記録します。

このパック自体では、プロファイル適合、レイヤープレビュー、印刷時間・PLA量、支持材を検証していません。
形状の存在や配置の確認は、スライス合格でも物理的な製造保証でもありません。
プリンター接続やPrint/Sendを自動実行する機能はありません。

## 現物を試す際の最少記録

最も緩い **+0.20 mm（ノッチ4）** から始めます。きつければ無理に押し込まず停止します。

- 実際のノズル径、PLA、プレート、使用したプロファイル・層高。
- 無理な力なしで着座するか。浮き・がた・底当たりがないか。
- 受けを軽く逆さにしたとき、自重で抜けるか。
- 5回の着脱後の亀裂・白化・緩みと、受けの屋根の破損有無。可能なら写真と雄軸の外径。

小さい穴を無理にノギスで測る必要はありません。未測定は未確認のまま記録します。
基本の嵌合を確認してから、段違い結合3部品を試します。
この小型試験だけで、大きな模型の荷重・衝撃・組立可能性が確認されたことにはなりません。

**物理嵌合・保持力・全体組立は未確認です。最終製造用のリリースではありません。**
